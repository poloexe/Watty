# Watty

iOS tweak for WhatsApp.

## Installation

### Jailbroken (Dopamine, palera1n, etc)

Download `Watty.deb` from the [latest release](../../releases/latest) and install via your favorite package manager.

### Jailed Devices

Download `Watty.dylib` from the [latest release](../../releases/latest) or get latest ipa on out [Telegram](https://t.me/+rh-GZahMajNhYzRk). If you downloaded the dylib instead then you can just inject dylib into the WhatsApp IPA using **Feather**, **Sideloadly** or any signing tool of your choice

## Something you should Know
I built this tweak completely for free and entirely on my own so there might be bugs. I have tested the features, hopefully well enough to work on y'all devices. If you encounter any problems please open an issue. Thank you.

## Supported

- iOS 14+
