# Watty

iOS tweak for WhatsApp.

## Installation

### Jailbroken (Dopamine, palera1n, etc)

Download `deb` from the [latest release](../../releases/latest) and install via your favorite package manager(rootless, rootful and roothide).

### Jailed Devices
Get the `dylib` from the [latest release](../../releases/latest), inject using feather, sidelaodly, ryuksign, etc.

### Features (For now)
- **Privacy**: Hide read receipt, disable typing indicator, disable recording indicator, freeze last seen

- **Chats & Media:** Unlimited View Once, Keep deleted messages, Show edited messages, Allow screenshots in view once, Unlimited pin chats, New chat menu, Video to Voice note, Confirm before calling

- **Statuses:** Save status media, Keep deleted statuses, Block status viewed receipt, Disable auto advance

- **NotifyMe:** Alerts for contact when typing, recording, online/offline, read messages

- **Notifications:** Keep the app in background for notifications, Stronger background to prevent ios from killing whatsapp

## Something you should Know
I built this tweak completely for free and entirely on my own so there might be bugs. I have tested the features, hopefully well enough to work on supported devices. If you encounter any problems please open an issue.
Though it is closed source for now, It is currently still in development but I have added some core features that would be needed anyway. I made this so I could integrate different cool features from all whatsapp tweaks like watusi, gold etc. if there is any feature you would like me to add please let me know
